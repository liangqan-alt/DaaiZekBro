# PR-09 训练日历安排需求分析

| 版本 | 日期 | 依赖 |
|---|---|---|
| v1.6 | 2026-05-24 | PR-01~PR-08（Core MVP + 模板与动作库 CRUD 完成） |

---

## 1. 目标

### 1.1 解决的问题

PPL 滚动周期（3练1休）要求用户脑内维护「今天是周期第几天、该练哪个模板」。进健身房时容易遗忘当前位置，需要翻历史记录推算，形成额外认知负担。

### 1.2 目标场景

- 进健身房前，打开 app 即知今天练什么，一键开始
- 了解未来几天的训练安排，提前规划健身时间

### 1.3 核心价值

**今天练什么，一键开始；这周怎么排，一眼看懂。**

---

## 2. 设计原则

1. **计划是规则，不是计划表**：训练周期定义模板顺序，app 按规则动态推算每天的安排；用户只需管理例外（覆盖某天），不需要逐日填写计划
2. **计划入口不替代现有记录流程**：从计划开始训练的行为与手动选模板一致，不引入新的 session 生命周期逻辑
3. **不引入系统日历框架，不依赖第三方库**

---

## 3. 范围

### 3.1 本次做

- 训练周期配置（定义槽位序列与起始日期）
- 首页「今日计划」卡
- 从今日计划直接开始训练
- 未来 7 天安排视图（计划展示 + 今日完成标注）
- 单日覆盖（改模板 / 改为休息 / 重置为周期默认）

### 3.2 本次不做

| 项 | 说明 |
|---|---|
| 月视图与完成差距可视化 | 核心流程稳定后再做 |
| 训练提醒通知 | 计划入口验证后的后续增强，而非无意义 |
| 多周期 / 周期模板库 | 单用户单周期已满足 PPL 场景 |
| 系统日历同步（EventKit / WorkoutKit） | 当前价值不明显，不为此引入额外权限 |
| 历史日期补录计划 | 不允许倒填，保持计划数据干净 |
| 无周期下的手动单日安排 | 本阶段以配置了滚动周期的用户为目标，不支持在无周期情况下直接安排单日训练 |

---

## 4. 数据概念变更

### 4.1 新增概念

**训练周期**：定义一次完整训练循环的槽位序列。每个槽位为某个训练模板或休息日，序列有序。同时记录周期的起始日期和创建时的时区。全局最多存在一个训练周期。

**周期推算安排**：app 根据训练周期规则即时推算每天的计划，不产生持久化数据。周期修改后，推算结果立即更新。

**覆盖记录**：用户显式修改某天计划安排（改为其他模板或改为休息日）时创建的持久化记录，代替周期推算结果作为当天的计划。覆盖记录可被「重置为周期默认」撤销；周期删除时同步清除。

### 4.2 现有概念微调

**模板颜色标记**：每个模板可设置一个颜色标记，用于在未来 7 天视图中区分不同训练类型。预置的 6 个模板各赋予默认颜色（Push 系暖色、Pull 系冷色、Legs 系绿色）；用户新建的模板默认无颜色（展示为灰色）。颜色仅影响视图展示，不影响任何训练记录数据。

## 5. 功能需求

### 5.1 训练周期配置

| 操作 | 说明 |
|---|---|
| 新建 | 选择模板或休息日，排列成有序槽位序列；指定起始日期。若已有周期，需先删除旧周期才能新建 |
| 编辑 | 可修改槽位顺序或起始日期；已手动覆盖某天的安排不受周期改动影响 |
| 删除 | 清空周期及所有覆盖记录；首页今日计划卡消失；删除前展示确认提示，明确告知将同时清除所有单日覆盖记录 |

**约束**：槽位序列至少包含一个模板槽，不能全为休息日。

**入口**：Settings → 训练安排

### 5.2 首页今日计划卡

根据当天状态展示不同内容，显示在首页模板列表上方：

| 当天状态 | 卡片内容 |
|---|---|
| 无训练周期 | 不显示卡片 |
| 今日为训练日，无已结束训练 | 显示计划模板名 + 上次该模板的完成时间；提供「开始训练」入口 |
| 今日为训练日，有与计划模板一致的已结束训练 | 显示「已完成」状态；不再提供「开始训练」入口 |
| 今日为训练日，仅有非计划模板的已结束训练 | 保留「开始训练」入口；显示弱提示「今日已有其他训练记录」 |
| 今日为休息日，无已结束训练 | 显示弱提示「今日：休息」；无操作按钮 |
| 今日为休息日，有已结束训练 | 显示弱提示「今日：休息 · 已有训练记录」；无操作按钮 |
| 今日有进行中的训练 | 不显示计划卡；保持现有「继续当前训练」卡片 |

今日计划卡与「继续当前训练」卡互斥，同一时刻只显示其中一个。当今日计划卡显示时（无论为训练日、休息日、已完成或失效状态），均可点击进入未来 7 天视图；操作按钮按当天状态显示或隐藏，卡片整体保持可跳转。

### 5.3 从今日计划开始训练

- 点击「开始训练」后，行为与手动从模板列表选择模板完全一致
  - 若无进行中的训练：直接创建训练 session 并进入训练页
  - 若已有进行中的训练：弹出三选一提示（继续当前 / 结束并新建 / 丢弃并新建），不自动覆盖现有 session
- 训练完成后，该 session 在未来 7 天视图中标注为「已完成」

### 5.4 未来 7 天安排视图

展示今天及未来 6 天（共 7 天）的训练安排。

每天展示：
- 计划模板的颜色色块 + 模板名（休息日显示「休息」标注）
- 完成状态标注（见下表）
- 今天高亮显示

**完成状态判定**（适用于今天；未来日期无已结束训练，不显示完成标注）：

| 当天情况 | 标注 |
|---|---|
| 有已结束训练，其中存在与计划模板一致的 | ✓ 已完成 |
| 有已结束训练，但无一与计划模板一致 | ✓ 已完成（非计划模板） |
| 有已结束训练，且存在与已失效计划模板一致的（模板已被删除） | ✓ 已完成（计划模板已删除） |
| 有已结束训练，但无一与计划模板一致；或当天为休息日、无计划安排 | 计划外训练 |
| 无已结束训练 | 无标注，显示计划安排 |

**入口**：Settings → 训练安排（进入后首先展示未来 7 天视图，周期配置作为该页的次级操作入口）；首页今日计划卡提供快速跳转。

### 5.5 单日覆盖

在未来 7 天视图中点击某天进入天详情页，可执行以下操作：

| 操作 | 说明 |
|---|---|
| 覆盖为其他模板 | 将当天的默认安排改为另一个模板；未来 7 天视图立即更新为覆盖后的模板 |
| 覆盖为休息日 | 将当天的训练日改为休息日 |
| 重置为周期默认 | 撤销手动覆盖，恢复为周期规则推算的结果 |

覆盖仅影响当天，不影响周期其他天。当日计划已按计划模板完成的训练日（有与计划模板一致的已结束训练）不允许覆盖；仅有非计划训练的天不受此限制。

## 6. 业务规则

- 全局最多一个训练周期；新建前已有周期时，app 提示先删除，不支持静默替换
- 修改周期槽位顺序或起始日期后，已手动覆盖的天保留覆盖结果，不被新周期推算值覆盖
- 覆盖记录引用的模板被删除后，该天计划标注为「计划已失效」，不影响其他天的展示；周期推算安排引用的模板同理
- 模板改名后，周期槽位和覆盖记录显示改名后的最新模板名称；只有模板被删除时才显示「计划已失效」
- 起始日期可设在过去，历史日期按规则推算展示，但不允许补录历史覆盖记录
- 同一天有多个已结束的训练时，完成标注以是否存在与计划模板一致的 session 为准，而非以时间顺序为准
- 完成状态按模板身份判断，不按名称比较；模板改名不影响该模板已完成训练的匹配
- 「计划已失效」的日期仍支持单日覆盖（改为其他模板或改为休息日），不受「已完成的训练日不允许覆盖」的限制
- 计划日期及「今天」的判定均以训练周期创建时记录的时区为准；训练 session 按 startedAt 转换到该时区后匹配日期，跨午夜训练归属开始日期

---

## 7. 边界与异常

| 场景 | 处理方式 |
|---|---|
| 无训练周期 | 首页无今日计划卡；未来 7 天视图显示空状态并提示前往配置 |
| 今日计划模板被删除 | 首页计划卡显示「计划已失效」；不提供「开始训练」入口；若当天已有与已失效模板一致的已结束训练，未来 7 天视图标注「已完成（计划模板已删除）」；若已结束训练与已失效模板不一致，则标注「计划外训练」 |
| 槽位全为休息日时尝试保存周期 | 校验拦截，提示至少需要一个模板槽 |

---

## 8. 验收标准

- 当配置了训练周期后，首页应根据当天在周期中的位置，正确显示对应模板名或「今日：休息」弱提示
- 当无训练周期时，首页不应出现今日计划卡；未来 7 天视图应显示空状态并引导配置
- 当点击今日计划卡的「开始训练」且无进行中的训练时，应直接以计划模板创建 session 并进入训练页
- 当点击「开始训练」且已有进行中的训练时，应弹出三选一提示，不自动覆盖现有 session
- 当今日有与计划模板一致的已结束训练时，首页计划卡应变为「已完成」状态，不再提供「开始训练」入口
- 当今日仅有非计划模板的已结束训练时，首页计划卡应保留「开始训练」入口，并显示「今日已有其他训练记录」弱提示
- 当今日有进行中的训练时，首页应显示「继续当前训练」卡片，不同时显示今日计划卡
- 当修改周期槽位顺序或起始日期后，未来 7 天视图应按新规则推算显示；已手动覆盖的天不受影响
- 当手动将某天覆盖为休息日后，该天在未来 7 天视图中应显示为「休息」
- 当重置某天覆盖后，该天应恢复为周期推算的模板或休息状态
- 当计划中引用的模板被删除后，对应天应显示「计划已失效」，其余天的展示不受影响；若该天已有与已失效模板一致的已结束训练，未来 7 天视图应标注「✓ 已完成（计划模板已删除）」；若已结束训练与已失效模板不一致，则标注「计划外训练」
- 当「计划已失效」的日期执行单日覆盖操作时，应正常创建覆盖记录，不被已完成限制拦截
- 当今日为休息日且有已结束训练时，首页应显示「今日：休息 · 已有训练记录」，不提供「开始训练」入口；未来 7 天视图应标注「计划外训练」
- 当计划模板改名后，使用该模板完成的训练 session 应仍被识别为「已完成」，不因名称变化导致匹配失效
- 当天有已结束训练且模板与计划一致时，未来 7 天视图应显示「✓ 已完成」标注
- 当天有已结束训练但模板与计划不同时，未来 7 天视图应标注「✓ 已完成（非计划模板）」
- 删除训练周期后，首页今日计划卡应消失，覆盖记录应同步清除
