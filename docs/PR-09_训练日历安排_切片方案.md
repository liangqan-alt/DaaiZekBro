## 关键设计约束（须在 Slice 0–1 阶段解决）

**模板删除后的身份比较**

模板删除后，系统仍须用稳定模板身份判断完成状态和覆盖封锁。不得依赖名称或当前对象引用。Slice 0 建立数据约束，Slice 1 验证推算逻辑；后续切片依赖这一能力。

## Slice 0：数据基础

**目标**：系统能保存训练周期、槽位、覆盖和模板身份；升级后旧训练记录仍可读；周期删除和模板删除规则可验证。

**包含**

- 训练周期可持久化，包含起始日期、创建时区、有序槽位序列和单日覆盖记录；周期删除时关联的槽位和覆盖同步清除
- 模板删除时，引用该模板的槽位和覆盖记录保留，进入「计划已失效」语义；休息日与「计划已失效」在数据层可区分，不依赖 UI 推断
- 单日覆盖在同一周期内对同一日期唯一，不产生同天多条冗余记录
- 模板具备稳定业务身份，支持跨删除操作的匹配；升级时已有模板补齐身份标识
- template 关系仍存在的旧 session 可参与模板身份匹配；关系已断的旧 session 保持现有行为，不回溯
- 预置模板颜色写入（Push 系暖色、Pull 系冷色、Legs 系绿色）；用户新建模板颜色为空（展示灰色）；颜色编辑不在本 PR 范围内

**不包含**：业务逻辑、UI、服务层代码

**验收标准**
- App 在含有旧数据的设备上升级后正常启动，已有训练记录不丢失
- 所有模板（含升级前已有）均具备稳定身份标识
- 周期删除后，其所有槽位和覆盖记录消失
- 模板删除后，引用该模板的槽位和覆盖记录仍存在，且可被标记为「计划已失效」而非误判为休息日

**核心测试**
- 创建周期 + 槽位 + 覆盖，删除周期，验证槽位和覆盖均被清除
- 创建槽位（训练日），删除被引用模板，槽位记录仍存在，身份标识保留，状态可被识别为「计划已失效」而非休息日
- 创建覆盖记录（训练日），删除被引用模板，覆盖记录仍存在，身份标识保留，状态可被识别为「计划已失效」而非休息日
- 同一天多次创建覆盖，结果只有一条记录
- 升级路径（身份）：含旧数据的夹具升级后，升级前已有的所有模板均具备稳定身份标识；旧训练记录可读取
- 升级路径（session）：template 关系仍存在的 session 升级后可参与模板身份比较，能提供日期、结束状态与模板身份来源；关系已断的不报错、不回溯
- 升级路径（删除后匹配）：旧 session 的 template 关系存在 → 升级 → 删除该模板 → session 仍保留可用于身份匹配的来源数据，不因删除而丢失
- 颜色数据：预置 Push / Pull / Legs 系模板各具备默认颜色；新建模板颜色为空
- 时区持久化：保存非设备时区的周期后重载，起始日期和创建时区保持不变

## Slice 1：推算引擎（业务规则验证，无 UI）

**目标**：给定日期和周期配置，系统能推算该天计划与完成状态；所有业务规则通过测试验证。

**包含**

- 周期校验：槽位序列至少含一个训练模板，不能全为休息日
- 日期推算：给定日历日期，按周期时区映射到槽位序列；覆盖记录优先于周期推算；覆盖被重置后恢复推算结果
- 同一天重复设置覆盖时，只保留一条有效覆盖记录，后一次设置替代前一次结果；日期按周期时区归属到对应日历日
- 完成状态计算（5 种分支）：以该日有效计划（含覆盖后）的模板身份为准，不以名称或原始槽位为准
- 训练 session 创建时保留模板稳定身份，供删除后比较；本切片须验证此写入路径，不仅限于推算逻辑
- 封锁规则判断：当天有与有效计划模板身份一致的已结束训练时，覆盖不可用；仅有非计划训练或计划已失效时不受限
- 周期唯一性：系统任一时刻只接受一个有效周期；已有周期时创建第二个周期被明确拒绝，不依赖调用方先删除

**不包含**：UI；导航路由；7 天数据组装

**验收标准**
- 周期推算在 3练1休场景跨月、跨年均正确
- 覆盖记录优先返回；重置后恢复推算结果
- 模板被删除后，已有训练 session 仍可通过稳定身份识别为「已完成（计划模板已删除）」

**核心测试**
- 跨月边界：PPL 6 槽起始 2026-01-29，查询 day 0~5，验证跨 1→2 月槽位映射正确
- 跨年边界：PPL 6 槽起始 2026-12-30，查询 day 0~5，验证跨 12 月→1 月槽位映射正确
- 同一天有覆盖：推算返回覆盖模板而非周期默认
- 覆盖重置：创建覆盖 → 推算返回覆盖结果 → 重置覆盖 → 推算恢复周期默认
- 完成状态分支前提映射：有效计划 + 匹配 session → 「✓ 已完成」；有效计划 + 仅非匹配 session → 「✓ 已完成（非计划模板）」；失效计划 + 身份匹配 session → 「✓ 已完成（计划模板已删除）」；失效计划 + 非匹配 session → 「计划外训练」；休息日或无计划 + session → 「计划外训练」；无 session → 无标注
- 多 session 顺序无关：同一天存在计划匹配和非计划两条已结束训练，匹配在前和匹配在后两种顺序均显示「✓ 已完成」
- 覆盖后完成：Push 槽覆盖为 Pull，完成 Pull 后状态为「✓ 已完成」且封锁判断返回不可覆盖
- 时区边界：周期时区 UTC+8，session startedAt = 2026-01-01 23:59，endedAt = 2026-01-02 00:30；查询 2026-01-01 命中，查询 2026-01-02 不命中
- 同天两次覆盖（不同模板），结果唯一且为第二次的值
- 周期唯一性：已有周期时发起创建，操作被拒绝，原周期不变
- session 写入路径：通过训练创建流程（非夹具）生成模板 A 的 session，删除模板 A 后，推算识别为「✓ 已完成（计划模板已删除）」
- 升级夹具推算：以含旧 session（升级前有 template 关系）的夹具驱动推算，删除对应模板后，对应日期识别为「✓ 已完成（计划模板已删除）」

## Slice 2：Settings 入口 + 周期 CRUD + 7 天安排视图

**目标**：用户可通过 Settings 进入训练安排页，查看 7 天计划，并在此创建、编辑、删除训练周期；7 天视图实时反映周期变更和计划失效状态。

**包含**

- Settings 新增「训练安排」入口，导航至训练安排页
- 7 天安排视图：
  - 展示今天起 7 天，每天显示计划模板颜色、名称（或「休息」标注）
  - 今天高亮；今天显示完成状态标注（5 种）
  - 槽位引用的模板被删除时，对应天显示「计划已失效」
  - 无周期时显示空状态，引导前往配置
- 周期配置（作为训练安排页的次级操作入口）：
  - 新建：槽位序列选择 + 起始日期；槽位全为休息日时拦截保存
  - 编辑：调整槽位顺序或起始日期
  - 删除：确认告知将同时清除所有单日覆盖，确认后执行

**不包含**
- 首页今日计划卡（Slice 3）；单日覆盖入口（Slice 4）；模板颜色编辑（仅展示，不提供修改入口）
- 覆盖记录只验证已有数据的展示与保留
- 不提供创建、编辑、重置覆盖的用户入口；测试数据来自夹具或已有数据

**验收标准**
- Settings 有「训练安排」入口，可导航至训练安排页
- 无周期时，训练安排页显示空状态并引导配置
- 创建 PPL 6 槽周期后，7 天视图立即显示对应颜色和模板名
- 起始日期可设在过去，7 天视图按周期规则正确推算今天及未来 6 天的安排
- 已有周期时，新建操作提示须先删除现有周期，不允许静默替换
- 修改槽位顺序或起始日期后，7 天视图按新规则刷新；已单日覆盖的天仍显示覆盖结果，不被新推算值覆盖
- 删除周期前出现确认提示，明确告知将同时清除所有单日覆盖记录；确认后视图恢复空状态，覆盖记录已清除
- 槽位引用的模板被删除后，7 天视图对应天显示「计划已失效」，其余天不受影响
- 某天的单日覆盖引用的模板被删除后，该天显示「计划已失效」，其余天不受影响

**核心测试**
- 7 天视图状态：无周期显示空态；有周期列出 7 天颜色与名称；休息日槽位标「休息」；槽位模板被删除时标「计划已失效」
- 今天完成状态各分支（含前提）：有效计划 + 匹配 session → 「✓ 已完成」；有效计划 + 仅非匹配 session → 「✓ 已完成（非计划模板）」；失效计划 + 身份匹配 session → 「✓ 已完成（计划模板已删除）」；失效计划 + 非匹配 session → 「计划外训练」；休息日或无计划 + session → 「计划外训练」；无 session → 无标注；未来 6 天无标注
- 覆盖记录失效：某天覆盖为模板 A，删除模板 A，该天显示「计划已失效」，其余天不受影响
- 模板改名：将被槽位引用的模板改名，7 天视图显示新名称；将被覆盖记录引用的模板改名，对应天显示新名称；完成身份匹配不受改名影响
- 静默替换拦截：已有周期时发起新建，操作被拦截并提示须先删除现有周期，现有周期不变
- 编辑保留覆盖（槽位顺序）：修改槽位顺序后，已有单日覆盖的天仍显示覆盖结果，不被新推算值覆盖
- 编辑保留覆盖（起始日期）：准备已有单日覆盖记录，修改起始日期后，覆盖日期仍显示覆盖结果，未覆盖日期按新起始日期推算
- 槽位全为休息日时，保存操作被拦截
- 颜色展示：预置 Push / Pull / Legs 系模板在 7 天视图中显示各自默认色；用户新建模板无颜色时展示灰色；不出现颜色编辑入口
- 时区集成：周期以 UTC+8 创建，设备时区为 UTC，7 天视图「今天」高亮和完成状态均以 UTC+8 为准；需使用固定 now 时间戳，使 UTC 与 UTC+8 落在不同日历日

## Slice 3：首页今日计划卡 + 从计划开始训练

**目标**：用户打开 app 即能看到今日计划卡（所有状态变体），可一键开始训练或跳转 7 天视图。

**包含**

- 首页模板列表上方插入今日计划卡，展示 7 种状态：
  - 无周期：不显示卡片
  - 训练日无已结束训练：显示模板名 + 上次该模板完成时间；提供「开始训练」
  - 训练日有计划匹配的已结束训练：显示「已完成」；不提供「开始训练」
  - 训练日仅有非计划训练：保留「开始训练」；显示「今日已有其他训练记录」弱提示
  - 休息日无已结束训练：显示「今日：休息」弱提示；无操作按钮
  - 休息日有已结束训练：显示「今日：休息 · 已有训练记录」；无操作按钮
  - 今日计划模板已失效：显示「计划已失效」；不提供「开始训练」
- 今日计划卡与「继续当前训练」卡互斥；有进行中训练时隐藏计划卡
- 计划卡整体可点击，导航至 7 天视图
- 「开始训练」进入与手动选模板相同的训练流程；冲突处理复用现有机制，不新增 UI 路径

**不包含**：单日覆盖（Slice 4）

**验收标准**
- 配置周期后，首页显示今日模板名（训练日）或「今日：休息」弱提示（休息日）
- 训练日无今日已结束训练时，计划卡显示上次同模板完成时间（若从未完成则不显示）
- 训练日、休息日、已完成、计划已失效状态下，点击计划卡主体（非按钮区域）均进入 7 天视图
- 有进行中训练时，计划卡不显示，「继续当前训练」卡可见
- 点击「开始训练」且无进行中训练时，直接创建训练并进入训练页
- 今日有与计划匹配的已结束训练时，计划卡显示「已完成」，不提供「开始训练」
- 今日仅有非计划训练时，计划卡保留「开始训练」，并显示弱提示
- 今日为休息日且有已结束训练时，计划卡显示「今日：休息 · 已有训练记录」，不提供「开始训练」
- 今日计划模板被删除时，计划卡显示「计划已失效」，不提供「开始训练」

**核心测试**
- 7 种卡片状态的 UI 层验证：检查文案内容、按钮显隐，以及计划卡与「继续当前训练」卡互斥；逻辑层测试可作为补充
- 端到端闭环：从今日计划开始并完成训练后，首页计划卡变为「已完成」，7 天视图今日标注「✓ 已完成」
- 时区集成：周期以非设备时区创建，今日计划卡的日期判断和完成状态匹配均以周期时区为准；需使用固定 now 时间戳，使周期时区与设备时区落在不同日历日
- 冲突保护：触发计划开始训练动作时若已有进行中训练，进入现有三选一冲突处理，不自动新建或覆盖 session
- 计划卡点击区域：训练日、休息日、已完成、计划已失效等无按钮状态，点击卡片主体均进入 7 天视图
- 上次完成时间精确性：同模板有较旧完成记录、其他模板有较新完成记录时，显示同模板的上次时间；从未完成该模板时不显示
- 删除周期后首页同步：创建周期 → 首页显示今日计划卡 → 进入 Settings 删除周期并确认 → 返回首页，今日计划卡消失

## Slice 4：单日覆盖

**目标**：用户可在 7 天视图点击任意一天，在天详情覆盖当天计划或重置为周期默认；完成封锁和失效计划的例外均按规则处理。

**包含**

- 7 天视图中每天可点击进入天详情页
- 天详情提供三项操作：覆盖为其他模板；覆盖为休息日；重置为周期默认
- 封锁规则：当天有与有效计划模板一致的已结束训练时，覆盖操作不可用；仅有非计划训练或计划已失效时不受限
- 今天和未来日期支持覆盖；历史日期（早于今天，按周期时区判断）不提供覆盖操作

**不包含**：颜色编辑；历史统计；多周期

**验收标准**
- 覆盖为另一个模板后，7 天视图该天显示新模板名和对应颜色
- 覆盖为休息日后，7 天视图该天显示「休息」
- 重置后，该天恢复为周期推算的模板或休息状态
- 当天已按计划完成训练时，覆盖操作入口不可用
- 当天仅有非计划已结束训练时，覆盖操作入口仍可用
- 「计划已失效」的天允许正常覆盖，不被已完成限制拦截

**核心测试**
- 覆盖为其他模板后 7 天视图显示新模板名；覆盖为休息日后显示「休息」；重置后恢复周期推算结果
- 覆盖后完成闭环：Push 槽覆盖为 Pull，完成 Pull 后 7 天视图显示「✓ 已完成」且覆盖入口不可用
- 已完成训练日（按有效计划身份匹配）：覆盖入口不可用
- 「计划已失效」天且已有与失效模板身份一致的已结束训练：覆盖入口仍可用，覆盖记录正常写入
- 失效计划覆盖后重算：今天模板 A 已删除、已有 A 身份的已结束 session → 覆盖为模板 B → 7 天视图和首页显示 B；无 B 的已结束 session 时完成标注为无标注，旧 A session 不再计入计划匹配
- 仅有非计划训练不触发封锁：当天只有非计划模板的已结束训练时，覆盖入口可用，可覆盖为其他模板或休息日
- 覆盖后即时重算：今天默认 Push、已有 Pull 已结束 session → 覆盖为 Pull → 无需新训练，7 天视图和首页立即显示「✓ 已完成」，覆盖入口不可用
- 覆盖范围隔离：覆盖某一天后，该天显示覆盖结果，前后相邻日期仍按周期默认显示；重置也仅恢复该天，相邻日期不受影响
- 历史日期封锁（逻辑/防御性测试）：当前 UI 不提供历史日期详情入口；周期时区与设备时区不同时，昨天（以周期时区为准）封锁判断返回不可覆盖，今天和未来日期可正常覆盖
- 覆盖今天后首页同步：将今天覆盖为其他模板或休息日后，返回首页，今日计划卡显示覆盖后的模板名或「今日：休息」，按钮显隐按覆盖后的有效计划执行
- 覆盖后开始训练闭环：今天默认 Push → 覆盖为 Pull → 返回首页点击「开始训练」→ 验证创建 Pull session → 完成后首页和 7 天视图均显示「✓ 已完成」
- 重置后首页同步与开始训练：今天默认 Push → 覆盖为 Pull → 重置为周期默认 → 返回首页显示 Push → 点击「开始训练」创建 Push session
