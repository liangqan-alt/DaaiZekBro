# PR-10 首页重设计：切片交付计划

| 版本 | 日期 |
|---|---|
| v1.3 | 2026-05-26 |

## 背景

PR-09 已引入今日计划卡和模板颜色数据；本 PR 在此基础上将首页重组为三区布局，使今日计划成为首屏核心，并为训练历史提供前置入口。切片顺序：先结构骨架，再高风险视觉变更（Carousel），最后接入新数据概念（有效完成记录）。

---

## 前置依赖

依赖 PR-09 已合入的今日计划/继续当前训练规则和模板颜色数据。若实现中发现前置能力有缺口，回 PR-09 或开独立 PR 修复，不在本 PR 补齐。

---

## Slice 1：首页三区骨架 + 导航栏精简

**目标**：首页完成结构重组，导航栏去除 logo，「编辑」入口完成迁移。

**包含**：
- 浏览态导航栏仅保留设置按钮，无 logo、无页面标题
- 三区结构就位：今日计划区（复用 PR-09 组件）→ 模板区（标题行含「编辑」）→ 最近训练区（标题行含「全部 →」）
- 编辑模式导航栏：切换为「+」+「完成」，隐藏设置按钮
- 最近训练区：空状态文案占位，无实际数据接入
- 「全部 →」已接入既有训练历史页导航，不查询最近训练数据
- 模板区：内容保持现有展示，Carousel 在 Slice 2 引入

**不包含**：Carousel 布局、模板颜色渲染、训练历史数据查询

**验收标准**：
- 浏览态导航栏仅显示设置按钮，不出现 app logo、页面标题或大标题空白
- 今日计划卡显示规则与 PR-09 一致
- 有进行中训练时：显示「继续当前训练」卡，今日计划卡不显示，点击进入当前训练页
- 点击「编辑」：导航栏切换为「+」+「完成」，设置按钮消失
- 点击「完成」：回浏览态，设置按钮恢复
- 模板区标题行显示「编辑」；最近训练区显示空状态标题行和「全部 →」入口，点击进入既有训练历史页

---

## Slice 2：模板区 Carousel + 颜色渲染

**目标**：模板区切换为 Carousel，卡片渲染已保存颜色，所有现有模板交互行为不退化。

**包含**：
- 模板区改为 Carousel 布局，右侧 peek 提示可滑动
- 卡片背景 = 已保存颜色；缺失或无法识别时渲染默认底色
- 无模板时：空状态文案，不显示空白滑动轨道，无独立新建按钮
- 编辑模式入口及操作行为不变（List + 拖排 + 删除）

**不包含**：颜色选择 UI、新建模板颜色自动分配、训练历史数据接入

**风险接受**：颜色数据由 PR-09 引入，本切片不做数据修复；颜色不影响启动、排序、删除逻辑

**验收标准**：
- 有颜色数据的模板：卡片渲染对应颜色；颜色缺失时渲染默认底色，不报错
- 左右滑动：可浏览全部模板，右侧 peek 可见
- 点击、长按、编辑模式（拖排/删除）：行为与重设计前一致
- 无模板时：空状态出现，无空白滑动轨道

**核心测试**：
- 删除最后一个模板，验证空状态正确显示
- 无模板时，走「编辑 → + → 保存」创建一个模板，验证回到编辑模式后模板出现
- 有进行中训练时点击模板，验证冲突弹窗弹出、各选项行为正确

---

## Slice 3：最近训练区数据接入

**目标**：最近训练区展示真实有效完成记录，「全部 →」导航路径可用。

**有效完成记录**（仅用于首页，不影响训练历史页口径）：已结束 + 至少含 1 组数据的训练记录

**包含**：
- 查询并展示最近 3 条有效完成记录，按开始时间倒序
- 每条显示：日期（含星期）、模板名称、组数、时长；展示口径与训练历史列表保持一致
- 条目不可点击进入详情
- 空状态：保留标题行、「全部 →」入口，显示说明文案
- 验证「全部 →」与「设置 → 训练历史」指向同一页

**不包含**：训练历史页改动、分页或展开更多

**验收标准**：
- 有有效完成记录时：最多展示 3 条，字段（日期/星期/模板/组数/时长）齐全，且同一记录与训练历史列表展示口径一致
- 超过 3 条时：只显示最新 3 条
- 无有效完成记录时：空状态文案，「全部 →」仍可点击
- 有记录/无记录时点击「全部 →」：均进入同一训练历史页
- 点击条目：无跳转，页面不变

**核心测试**：
- 完成一次含组数据的训练，验证首页出现该记录
- 结束一次不含任何组数据的训练，验证首页不出现该记录
- 有进行中训练且已记录组数据时，验证首页最近训练区不出现该记录；结束该训练后验证出现
- 累计 4 条有效记录后，验证首页只展示最新 3 条
