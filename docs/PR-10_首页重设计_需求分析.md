# PR-10 首页重设计需求分析

| 版本 | 日期 | 依赖 |
|---|---|---|
| v2.4 | 2026-05-26 | PR-01~PR-09（含首页今日计划卡） |

---

## 1. 目标

### 1.1 解决的问题

首页以「训练模板」为功能主体，存在以下问题：

- 今日计划是核心用户行为（进健身房 → 看今天练什么 → 开始），但视觉权重与模板列表持平，缺乏层级
- 训练历史入口藏在设置里，需两步导航才能到达
- 模板网格（2 列）占满首屏，今日计划卡在有周期时才出现在上方，用户感知弱
- 模板卡片已存储颜色数据（PR-09 Slice 0 引入），但首页没有使用

### 1.2 目标场景

- 用户进健身房：打开 app → 首屏直接看到今日计划 → 一键开始，路径不变但视觉优先级提升
- 用户查看历史：首页展示最近 3 条有效完成记录 + 「全部」入口，无需进入设置

### 1.3 核心价值

**打开即知今日，历史随手可得，模板操作不退化。**

---

## 2. 设计原则

1. **今日计划是首屏第一视觉层级**：不是「可选卡片」，而是首页的主体区域
2. **模板操作保持现有行为**：首页改为 Carousel 展示，启动、重命名、删除、排序流程不变
3. **训练历史入口前置到首页**：首页常驻「全部 →」入口；「设置 → 训练历史」入口保留
4. **不引入 Tab 导航重构**：本次只重组首页布局，导航架构不变

---

## 3. 范围

### 3.1 本次做

- 首页布局重组为三区：今日计划区 → 模板区 → 最近训练区
- 模板卡片使用已保存颜色
- 模板编辑入口（「编辑」按钮）从导航栏移至模板区标题行右侧
- 模板区有空状态设计
- 训练历史入口：最近训练区提供「全部 →」导航到训练历史页
- 取消首页导航栏中的 app logo

### 3.2 本次不做

| 项 | 说明 |
|---|---|
| Tab 导航重构 | 结构改动大，本次只重组首页视觉，不改导航架构 |
| 模板颜色选择 UI | 本次只展示已保存颜色，不新增颜色选择器 |
| 新建模板颜色 | 本次不自动分配颜色 |
| 训练历史页 | 保持现有行为；首页只新增最近训练摘要 |
| 训练安排页 | 保持现状 |
| 设置里的训练历史入口 | 保留现有入口，不删除 |

## 5. 功能需求

### 5.1 今日计划区

今日计划区沿用 PR-09 规则。无周期时隐藏；有进行中训练时显示「继续当前训练」。卡片内容不变。本 PR 只调整位置和样式。

### 5.2 模板区（以 Carousel 形式展示）

除布局从网格改为 Carousel 外，模板的启动、冲突处理、重命名、删除、排序和新建流程均保持现有行为。

| 操作 | 结果 |
|---|---|
| 点击模板卡片 | 触发启动或冲突确认 |
| 左右滑动 | 浏览全部模板 |
| 长按模板卡片 | 弹出上下文菜单（重命名、删除） |
| 点击「编辑」 | 进入编辑模式（List + 拖排 + 删除） |
| 编辑模式：拖动排序 | 保存拖排结果 |
| 编辑模式：滑动删除 | 沿用现有删除流程 |
| 编辑模式：点击「+」新建按钮 | 进入新建模板命名页 |
| 编辑模式：点击「完成」 | 退出编辑模式，回到模板区浏览视图 |
| 编辑模式：点击模板行 | 进入模板编辑页，沿用现有模板编辑流程 |
| 新建模板保存后 | 回到编辑模式，新模板出现在列表中 |

**卡片展示内容**：模板名称、动作数量和模板颜色。颜色缺失或无法识别时使用默认底色。颜色不影响启动、排序或删除。

**空状态**：无模板时，模板区显示说明文字。用户点击「编辑」后，可通过「+」新建模板。浏览态不显示独立新建按钮，也不显示空白滑动轨道。

### 5.3 最近训练区

**有效完成记录**：已结束且至少包含 1 组数据的训练记录。有效完成记录口径仅用于首页最近训练摘要；训练历史页的列表口径保持现有行为。

最近训练区最多展示 3 条有效完成记录，不分页、不展开，每条显示：

- 训练日期（含星期）
- 模板名称
- 组数
- 时长

最近训练条目仅展示摘要，不提供点击进入详情；用户通过「全部 →」进入训练历史页查看详情。

**排序**：按开始时间倒序（最新在上）。

**入口**：标题行右侧显示「全部 →」，与「设置 → 训练历史」指向同一训练历史页。

**空状态**：无有效完成记录时，最近训练区不显示记录列表。最近训练区保留标题行和「全部 →」入口，并显示文案：「完成训练后会在这里显示最近记录」。

---

## 6. 业务规则

- 最近训练区只展示记录，不创建、编辑或删除训练记录
- 浏览态导航栏仅显示设置按钮
- 首页不显示 app logo、页面标题或大标题空白
- 「编辑」显示在模板区标题行
- 编辑态导航栏右上角显示「+」新建按钮和「完成」
- 编辑态隐藏设置按钮
- 「+」新建按钮不移至列表底部

---

## 7. 边界与异常

| 场景 | 处理方式 |
|---|---|
| 无训练周期且无进行中训练 | 今日计划区不显示 |
| 有进行中的训练（无论有无训练周期） | 显示「继续当前训练」卡，今日计划卡不显示 |
| 无模板 | 显示模板区空状态 |
| 有效完成记录超过 3 条 | 最近训练区只显示最新 3 条，不提供加载更多 |
| 无有效完成记录 | 不显示记录列表，保留标题行、「全部 →」入口和说明文案 |
| 模板颜色缺失或无法识别 | 卡片渲染默认底色；本 PR 不做数据修复、迁移或错误提示 |

---

## 8. 验收标准

- 首页打开：导航栏不应出现 app logo、页面标题或大标题空白占位，仅显示设置按钮
- PR-09 今日计划卡应显示时：对应卡片在首页最上方
- 有进行中训练时：显示「继续当前训练」卡，今日计划卡不显示
- 今日计划卡显示「开始训练」按钮时：点击后进入对应训练页
- 有进行中训练时：点击「继续当前训练」进入当前训练页
- 点击今日计划卡非按钮区域：沿用 PR-09 既有导航行为
- 无训练周期且无进行中训练时：模板区成为首个业务区块，最近训练区在最下方
- 左右滑动模板区：应能浏览所有模板
- 模板有已保存颜色时：卡片背景渲染对应颜色
- 模板颜色缺失或无法识别时：卡片背景渲染默认底色
- 无进行中训练时点击模板区模板：直接进入对应训练页
- 有进行中训练时点击模板区模板：弹出现有冲突处理弹窗
- 冲突弹窗中选择「继续当前训练」：进入当前训练页
- 冲突弹窗中选择结束或丢弃当前并新建：进入所点模板的新训练页
- 冲突弹窗中选择「取消」：停留首页，当前训练不变
- 长按模板区中的模板：显示「重命名」「删除」上下文菜单
- 长按模板并选择「重命名」：进入重命名页；保存后模板区显示新名称
- 删除无需确认的模板时：模板直接从模板区移除
- 删除流程显示确认时：取消后模板仍保留
- 删除流程显示确认时：确认后模板从模板区移除
- 删除最后一个模板后：模板区显示空状态
- 点击模板区「编辑」：切换为可拖排、可删除的列表模式
- 点击「编辑」后：导航栏右上角显示「+」新建按钮和「完成」，不显示设置按钮
- 编辑模式不显示列表底部新建入口
- 点击「完成」后：回到 Carousel 浏览视图，设置按钮恢复显示
- 编辑模式拖动排序并点击「完成」后：模板区按新顺序展示
- 无模板时：模板区显示说明文字，不显示空白滑动轨道，不出现独立新建按钮
- 无模板时点击「编辑」后：导航栏右上角显示「+」新建按钮
- 点击「+」新建按钮：进入新建模板命名页
- 编辑模式点击模板行：进入模板编辑页，可维护模板名称和动作列表
- 新建模板保存后：回到编辑模式，新模板出现在列表中，并可继续进入模板编辑页
- 存在有效完成记录时：首页最多展示最近 3 条记录，不分页、不展开
- 最近训练区只展示已结束且至少包含 1 组数据的训练记录
- 多条有效完成记录按开始时间倒序展示
- 每条最近训练记录显示日期、星期、模板名称、组数和时长
- 点击最近训练条目：不进入详情页，不改变当前页面
- 无有效完成记录时：最近训练区保留标题行、「全部 →」入口和说明文案，不显示记录列表
- 点击首页「全部」或「设置 → 训练历史」：进入同一训练历史页
