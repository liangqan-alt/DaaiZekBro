# PR-08 模板与动作库 CRUD 需求分析

| 版本 | 日期 | 依赖 |
|---|---|---|
| v1.0 | 2026-05-23 | PR-01~PR-07（Core MVP 完成） |

## 设计原则

- 预置数据（6 模板 / 19 动作）与用户数据无区别，均可编辑和删除
- 模板只能引用动作库中已有的动作——先建动作，再组装模板
- 动作名全局唯一，保存时禁止重名
- 历史训练记录（已完成的组数据）不受模板或动作的任何修改影响

## 数据模型变更

训练模板新增「排序」字段，持久化用户拖拽后的顺序（预置模板赋初始序号，新建模板追加末尾）

## 功能需求：动作库

| 操作 | 说明 |
|---|---|
| 新建 | 填写动作名（唯一）、默认组间休息时长（≥ 30 秒）、是否单侧动作 |
| 编辑 | 全部属性可修改；改名时重新校验唯一性 |
| 删除 | 自动从所有引用该动作的模板中移除；历史训练组数据不受影响 |

## 功能需求：训练模板

| 操作 | 说明 |
|---|---|
| 新建 | 输入模板名（唯一）；动作列表初始可为空 |
| 编辑动作列表 | 从动作库选择并添加；支持拖拽重排和单条移除 |
| 重命名 | 校验唯一性 |
| 重排顺序 | 拖拽调整模板在首页的显示顺序 |
| 删除 | 若有进行中的训练使用该模板，弹警告提示（不阻止删除）；历史 session 不受影响 |

## UI 入口与屏幕

| 入口 | 屏幕 |
|---|---|
| 设置 → 管理动作库 | 动作列表（全局管理：新建/编辑/删除）→ 动作编辑表单 |
| 模板列表页工具栏「编辑」| 全局编辑态：拖拽重排 + 删除红圈 + 新建模板按钮 |
| 长按模板卡片 | 上下文菜单：重命名 / 删除（无需进入编辑态） |
| 编辑态点进某个模板 | 模板编辑页：改名 + 动作列表增删重排（始终显示拖拽手柄，无需额外触发） |

**添加动作流程**：模板编辑页点「添加动作」→ 底部 Sheet 多选（打勾）→「完成」返回；Sheet 顶部「+ 新建动作」可内联创建，新建后自动勾选并计入本次添加
